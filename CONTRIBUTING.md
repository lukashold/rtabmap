# Contributing to Kantura

The development branch is [kantura/main](https://github.com/lukashold/rtabmap/tree/kantura/main). Target that branch for pull requests.

Read the full instructions in your language:

If GitHub forks only the default branch, fetch the development branch from this repository before starting your change. The clone command in the guides explicitly selects kantura/main.

Issue forms are prepared in this repository. The owner must enable Issues in GitHub Settings before the issue tracker can accept public reports.
