# Участие в KANTURA

KANTURA — независимый форк RTAB-Map. Разработка и запросы на слияние направляются в [`lukashold/rtabmap:kantura/main`](https://github.com/lukashold/rtabmap/tree/kantura/main). Полный процесс описан в [основном руководстве на английском](../../CONTRIBUTING.md).

## С чего начать

Прочитайте [руководство рабочей области](../../tools/scan-workspace/README.md), [сравнение возможностей](../KANTURA-FEATURES.md) и [результаты проверок](../../tools/scan-workspace/VALIDATION.md). Перед созданием обращения поищите похожее в [списке задач](https://github.com/lukashold/rtabmap/issues). Полезны воспроизводимые ошибки, небольшие улучшения интерфейса, переводы и испытания на реальном устройстве.

Для браузерной части нужен полный репозиторий, Node.js 24 и pnpm 11.25.0. Создайте свою ветку от `kantura/main`. Из `tools/scan-workspace` выполните:

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm check
pnpm build
pnpm start
```

Откройте `http://localhost:4173`. Настройка Corepack, Docker и хранилища описана в основном руководстве. Для изменений геометрии, архивов и сохранения данных нужны содержательные проверки. Для правки текста проверьте язык и вёрстку. Укажите, какие проверки действительно выполнены, а какие пока недоступны.

## Переводы и учебные материалы

Русский языковой пакет находится в `tools/scan-workspace/locales/ru.json`. Проверьте согласованность с нативным руководством `app/ios/RTABMapApp/MeasurementGuide.json` и сценариями видео `tools/scan-workspace/public/videos/scripts.json`. Сохраняйте ключи, идентификаторы сцен и значков, единицы и подстановочные параметры. Исправляйте субтитры и озвучку согласованно. Для обрезанного текста приложите снимок экрана.

Видео — синтетические анимации, а не реальные сканы. Сохраняйте это пояснение. RoomPlan предназначен для помещений; для ворот и наружных объектов используется LiDAR-сканирование. Отдельные комнаты не совмещаются автоматически. Проверка по эталону не гарантирует точность всего скана, а оценка переноса не проверяет все столкновения на реальном пути.

## Испытания на iPhone

Для сборки и подписи iOS нужны Mac, совместимый Xcode и нативные зависимости. См. [руководство по установке и выпуску](../APP-STORE-RELEASE.md). Скрипты `app/ios/Tests/run-scan-tracking-tests.sh` и `run-measurement-guide-tests.sh` не заменяют съёмку на устройстве.

В отчёте укажите ревизию, устройство, версию iOS, режим, шаги и ожидаемый/фактический результат. Сравнивая размеры с рулеткой, запишите оба значения, способ измерения и единицы. Отметьте, синтетические данные или реальные. По характеру изменений проверьте комнату, ворота, прерывание, сохранение/открытие, фотографии и экспорт. Не публикуйте частные интерьеры, людей, адреса, ключи и данные учётных записей без необходимых прав.

## Запрос на слияние и лицензии

Создайте форк и отдельную ветку от `kantura/main`, внесите ограниченное изменение и откройте PR в **`lukashold/rtabmap:kantura/main`**. Опишите проблему, итоговое поведение, проверки и ограничения. Общие исправления RTAB-Map можно предложить отдельно в исходный проект; интерфейс и рабочая область KANTURA относятся к этому форку. Обсуждайте изменения конструктивно.
